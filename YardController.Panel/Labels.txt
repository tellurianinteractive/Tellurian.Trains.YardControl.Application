' Key labels for the Stream Deck command pad.
'
' Same shape as the station files: a comment starts with an apostrophe, the first row names
' the languages, and every row after it is the icon's file name (without .svg), a colon, then
' one label per language separated by semicolons. An empty cell means that key carries its
' icon alone in that language.
'
' The word is the ACTION, never the object: the icon already says whether the key is about a
' point, a signal, a route or a train, and no object noun fits a 19 mm key in all five
' languages. "Vaxlingsomrade" and "Rangierbereich" are both fourteen characters; every verb
' below is nine or fewer.
'
' Swedish follows Messages.sv.resx, except that the point positions use the shorter, more
' idiomatic Rakt / Sido from the operating vocabulary rather than the resx's Avvikande.
'
' TODO Stefan: the Danish, Norwegian and German columns are drafts and want a native eye.
